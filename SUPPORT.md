# Support

Use [GitHub Issues](https://github.com/starcat-app/starcat-alfred-workflow/issues) for reproducible Workflow bugs and focused feature requests.

Before opening an issue:

- Search existing issues.
- Include the Workflow, Alfred, macOS, Starcat, and CLI versions.
- Include reproduction steps and the visible Alfred result.
- Remove pairing URIs, tokens, private repository names, notes, local paths, and other secrets from logs or screenshots.
- Keep one problem or request per issue.

For Starcat application, subscription, download, or product support, use [starcat-pro Issues](https://github.com/starcat-app/starcat-pro/issues). Report vulnerabilities privately through this repository's Security tab as described in [SECURITY.md](./SECURITY.md).
